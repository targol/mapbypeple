# انتشار نقشه روی هاست خودتان (cPanel / DirectAdmin / هر هاست استاتیک)

نقشه بعد از build فقط چند فایل ثابت است؛ PHP یا دیتابیس لازم ندارد.

## ۱. ساخت
```powershell
npm.cmd install
npm.cmd run build
```
پوشه‌ی `dist` ساخته می‌شود. همه‌ی مسیرها نسبی‌اند، پس در ریشه‌ی سایت، در یک پوشه (مثل `/map/`) یا روی زیردامنه کار می‌کند.

## ۲. آپلود
محتوای داخل `dist` (نه خود پوشه) را در مسیر دلخواه روی هاست آپلود کنید، مثلاً `public_html/map/`. بعد باز کنید:
`https://barzokhouse.com/map/`

## ۳. عکس و صدا روی همان هاست
ساختار روی هاست بعد از آپلود:
```
public_html/map/
  index.html
  assets/            ← خود برنامه (با هر build عوض می‌شود)
  audio.json         ← فهرست صداها (بدون build قابل ویرایش)
  audio/             ← فایل‌های صوتی
  images/barzok/     ← عکس‌ها
```
**صدا (بدون build مجدد):**
1. فایل صوتی (mp3 یا m4a، حدود ۶۴ تا ۹۶ کیلوبیت‌برثانیه) را با File Manager هاست در `map/audio/` آپلود کنید.
2. فایل `map/audio.json` روی هاست را ویرایش کنید:
   `{ "lodging-003": [{ "url": "audio/lodging-003.mp3", "titleFa": "قصه این مکان" }] }`
   شناسه‌ی هر مکان در `docs/places-index.csv` است.
3. صفحه را refresh کنید؛ پخش‌کننده در کارت پیاده‌روی و پنل مکان ظاهر می‌شود.

با آپلود دوباره‌ی `dist`، فایل `audio.json` و پوشه‌ی `audio` هاست را دست‌کاری نکنید یا قبل از آپلود نسخه‌ی هاست را نگه دارید.

**عکس:** عکس‌ها را در `map/images/barzok/` بگذارید و آدرسشان را به شکل `images/barzok/نام.jpg` در داده بنویسید (برای عکس‌های My Maps از KMZ استفاده می‌شود).

## ۴. قرار دادن در وردپرس
- لینک مستقیم: دکمه یا منو به `https://barzokhouse.com/map/`.
- یا داخل صفحه با ویجت HTML المنتور:
```html
<iframe src="https://barzokhouse.com/map/?embed=1" width="100%" height="700" style="border:0" allow="geolocation" allowfullscreen loading="lazy"></iframe>
```
`allow="geolocation"` برای GPS راهنمای پیاده‌روی لازم است و سایت باید HTTPS باشد.

## ۵. آدرس مکان‌ها (برای QR و اشتراک‌گذاری)
هر مکان: `https://barzokhouse.com/map/?place=<شناسه>` (شناسه‌ها در `docs/places-index.csv`).
این آدرس‌ها نیاز به تنظیم سرور ندارند.

## نکته‌ی مهم درباره‌ی ویرایش
تا وقتی دیتابیس روی هاست نیست، ویرایش پنل مدیر فقط در همان مرورگر ذخیره می‌شود. برای تغییر داده‌ی عمومی، فایل‌های `src/data/seed` یا `audio.json` را عوض کنید و دوباره build و آپلود کنید.

## عکس‌های My Maps را روی هاست ببرید
```powershell
npm.cmd run import:images
```
این دستور روی کامپیوتر خودتان همه‌ی عکس‌ها را از گوگل در `public/images/barzok/` ذخیره می‌کند و آدرس‌ها را به نسخه‌ی محلی تغییر می‌دهد. اگر چند عکس خطا داد، دوباره بزنید. بعد `npm.cmd run build` و آپلود.

## مسیرهای Wikiloc
فایل GPX هر مسیر را از Wikiloc دانلود کنید و بزنید:
```powershell
npm.cmd run import:gpx -- مسیر\فایل.gpx --slug=نام-مسیر
```
هر `slug` یک مسیر جدا می‌شود و مسیرهای قبلی پاک نمی‌شوند.


## عکس، صدا و فیلم از کتابخانه‌ی وردپرس
۱. عکس و صدا را در وردپرس آپلود کنید (رسانه ← افزودن).
۲. روی هاست، کنار `index.html` فایل `save-config.sample.php` را با نام `save-config.php` کپی کنید و تنظیمات ورود را بنویسید (بخش «ورود با حساب وردپرس» پایین). این فایل جزو بیلد نیست و با آپدیت پاک نمی‌شود.
۳. نقشه را با `?admin=1` باز کنید ← ورود ← «رسانه‌ی مکان‌ها (وردپرس)».
۴. مکان را انتخاب کنید ← «انتخاب از وردپرس» برای عکس و صدا، و لینک آپارات یا یوتیوب برای فیلم.
۵. رمز را بنویسید و «ذخیره روی هاست» را بزنید. نتیجه در `media.json` کنار `index.html` ذخیره می‌شود (نسخه‌ی قبلی در `media.backup.json`).

با آپلود دوباره‌ی نسخه‌ی جدید برنامه، `media.json` و `audio.json` را جایگزین نکنید.
اگر کتابخانه‌ی وردپرس باز نشد (افزونه‌ی امنیتی رابط REST را بسته)، آدرس مستقیم فایل را در کادر پایین صفحه بنویسید.

## ذخیره‌ی تغییرات پنل مدیریت روی هاست (`data.json`)

- تغییرات پنل مدیریت اول فقط در همان مرورگر ذخیره می‌شود. بالای پنل، نوار «انتشار روی هاست» نشان می‌دهد تغییر منتشرنشده دارید.
- با دکمه‌ی «انتشار روی هاست»، فایل `data.json` کنار `index.html` نوشته می‌شود (با نسخه‌ی پشتیبان `data.backup.json`). از آن پس همه‌ی بازدیدکنندگان همین داده را می‌بینند.
- مشارکت‌های مردمی و رسانه‌ها در `data.json` منتشر نمی‌شوند.
- توجه: وقتی `data.json` روی هاست هست، داده‌ی داخل `public/data` در بیلدهای بعدی دیده نمی‌شود؛ برای برگشت به داده‌ی اولیه، `data.json` را از هاست حذف کنید.

## عکس و صدا در فرم مکان

- فقط از آلبوم وردپرس انتخاب می‌شود. دکمه‌ی «انتخاب یا آپلود» پنجره‌ی آلبوم را باز می‌کند.
- آپلود فایل جدید از همان پنجره ممکن است و فایل در آلبوم وردپرس ذخیره می‌شود. برای آپلود، در وردپرس یک «Application Password» بسازید (کاربران ← پروفایل ← Application Passwords) و همراه نام کاربری وارد کنید. نقشه باید روی همان دامنه‌ی وردپرس باشد.
- ویدیو فقط لینک آپارات/یوتیوب است.

## کشیدن محله، باغ و مسیر قنات

در فرم مکان، «نوع و موقعیت روی نقشه» را روی «محدوده» (محله، باغ) یا «مسیر / خط» (قنات، کوچه) بگذارید و روی نقشه کلیک کنید. نقطه‌ها را بکشید تا جابه‌جا شوند؛ دوبار کلیک روی نقطه آن را حذف می‌کند. برای محله، لایه را «محلات» انتخاب کنید. برای هر مکان هم می‌توانید محله را دستی انتخاب کنید.

## ورود با حساب وردپرس (پیشنهادی)

نقشه را روی همان دامنه‌ی وردپرس بگذارید (مثلاً `barzokhouse.com/map/`). سپس:

1. `save-config.sample.php` را با نام `save-config.php` کپی کنید. مقدار `mode` را `'wordpress'` بگذارید. `capability` را `'manage_options'` (فقط مدیر کل) یا `'edit_pages'` (ویراستار و مدیر) بگذارید.
2. اگر `wp-load.php` خودکار پیدا نشد، مسیرش را در `wp_load` بنویسید.
3. از این پس فقط کسی که در وردپرس وارد شده است پنل را باز می‌کند و می‌تواند ذخیره کند. بقیه فقط نقشه را می‌بینند. دکمه‌ی «ورود مدیران» برای بازدیدکننده‌ی عادی نشان داده نمی‌شود. اگر کسی آدرس `?admin=1` را باز کند، پیام «ابتدا وارد وردپرس شوید» می‌بیند. نکته: امنیت واقعی در `save-data.php` روی سرور است و فقط مخفی‌کردن دکمه کافی نیست.
4. در نسخه‌ی جاسازی‌شده (`?embed=1`)، وقتی خودتان در وردپرس وارد شده‌اید دکمه‌ی «ویرایش نقشه» بالای نقشه دیده می‌شود.

اگر نمی‌خواهید به وردپرس وصل شوید، `mode` را `'password'` بگذارید و یک رمز طولانی در `password` بنویسید.

## آپدیت بدون از دست رفتن اطلاعات

هنگام کپی `dist` جدید روی هاست، این فایل‌ها را رونویسی نکنید (یا پیش از آن پشتیبان بگیرید): `data.json`، `media.json`، `audio.json`، `*.backup.json` و `save-config.php`.
